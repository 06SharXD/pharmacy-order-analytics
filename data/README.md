# Synthetic data

Every row in `raw/` and `cleaned/` is SYNTHETIC and generated by `python/generate_data.py` with seed `20261114`. No PharmEasy/company data, real pharmacy records, customer personal data, or prescription details are present. Raw files intentionally include a small number of planted data-quality defects; cleaned files retain documented rows and exclude/quarantine defects according to `data_quality/issue_register.csv`.
