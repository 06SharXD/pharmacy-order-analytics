# Project data

All rows in `raw/` and `cleaned/` are generated by `python/generate_data.py` with seed `20261114`. They are fictional sample records; no PharmEasy, pharmacy, customer or prescription records are used.

The raw files include a few planted data-quality issues for the validation examples. The cleaned files contain the rows retained after applying the documented rules. See `data_quality/issue_register.csv` for the affected issue types and dispositions.
